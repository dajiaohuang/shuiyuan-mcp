# Deepsearch Report Template

Use this format when the user wants a fuller research note.

```markdown
**Bottom Line**
One concise answer with confidence level.

**Findings**
- Finding 1.
- Finding 2.
- Finding 3.

**Evidence**
- Source or file reference: what it supports.
- Source or file reference: what it supports.

**Disagreement / Caveats**
- What sources disagree on.
- What remains uncertain.

**Recommended Next Step**
One or two practical actions.
```

Keep reports direct. Do not include every search result; include the evidence that changes the answer.
