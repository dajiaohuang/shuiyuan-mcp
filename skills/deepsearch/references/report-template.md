# Deepsearch Report Template

Use this format when the user wants a fuller research note.

```markdown
**Bottom Line**
One concise answer with confidence level and the date context if freshness matters.

**Findings**
- Finding 1.
- Finding 2.
- Finding 3.

**Evidence**
- Source or file reference: what it supports and why it is reliable.
- Source or file reference: what it supports and any freshness limits.

**Disagreement / Caveats**
- What sources disagree on.
- What remains uncertain.
- What would change the conclusion.

**Recommended Next Step**
One or two practical actions.
```

Keep reports direct. Do not include every search result; include the evidence that changes the answer.
